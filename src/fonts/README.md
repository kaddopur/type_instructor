# Chinese pixel font

Cubic 11 is used for Chinese characters and punctuation on Chinese routes.
Latin text, digits and kana keep the existing font stack. Other languages keep
using their existing fonts.

- Upstream: https://github.com/ACh-K/Cubic-11
- Pinned source revision: 4c566f7d6cc5c05ee360fe9cff56b5da1fcafd4d
- File: fonts/web/Cubic_11.woff2, copied without modification.

The font is bundled locally by Vite and precached by Workbox for GitHub Pages
and offline use. No external font service is required.
