# 本場錯題的生命週期

GameRoute 在記憶體保存完成場次、完整結果路徑與不透明識別碼。挑戰開始時清除前場資料。結果頁必須同時符合路徑與導覽識別碼，才能顯示練習。歷史紀錄只保存識別碼，不保存題目。

挑戰第一次有效答錯時，複製未標記的題幹、選項倍率、順序與正解。以當題已有的錯誤標記判斷是否保存過。同一題多次答錯只保存一次；逾時前尚未答對的錯題也保存。

練習使用獨立佇列，狀態分為作答、回饋與完成。回饋持續 500 毫秒後，答錯移到隊尾，答對移除。每次顯示都清除選項標記，只有一題時也適用。狀態不含分數、時間或個人紀錄。

結果頁擁有全畫面 Radix 對話框，沿用焦點限制與關閉還原。共用 QuestionPanel 保留原本題幹、回饋、選項及鍵盤焦點，挑戰繼續擁有自己的計時與計分。中英日、小螢幕與短橫向畫面都要能完成練習。

先驗證佇列與錯題保存，再做靜態檢查，最後一次執行正式建置的完整瀏覽器測試。截圖與實際結果記在驗證文件。
